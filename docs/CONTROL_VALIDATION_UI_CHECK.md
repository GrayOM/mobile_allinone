# 승인된 통제 검증 모드 UI 확인

검증 일시: 2026-08-12 (KST)

`/diagnostics/new`에서 새 **승인된 통제 검증 모드** 항목이 표시되는 것을 확인했다.

- Mock 모바일 진단 데모에서는 항목이 비활성화되고 `Live 진단에서만 사용할 수 있습니다.` 안내가 표시됐다.
- `Cyberone APK 증적 검증` 프로젝트는 실제 APK가 등록되어 있지만 Mock 실행 모드로 구성돼 있으므로 동일하게 비활성화되는 것을 확인했다.
- 따라서 합성 데이터용 프로젝트에서 동의 기록이 잘못 생성되는 경로는 UI에서 차단된다.
- Live 프로젝트와 준비된 실제 단말에서만 동의 다이얼로그와 승인 범위 입력을 사용할 수 있다.

이 검증은 UI 표시·모드 경계를 확인한 것이며, 실제 보안 통제 무력화 동작은 수행하지 않았다.
